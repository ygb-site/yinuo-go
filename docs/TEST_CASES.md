# 一诺成长空间（yinuo-go）功能与安全测试用例集

## 一、用例设计说明
本测试用例集覆盖项目全模块，包含：棋盘与规则引擎、课程学习与错题本、多版本课程表与学校层、激励系统与家庭银票、AI 伴学与少儿安全防护、认证权限与架构审计等。
用例优先级分为：
- **P0（致命/阻断）**：核心规则、资产安全、隐私泄漏、数据防刷、主流程阻断
- **P1（严重）**：重要业务分支、版本兼容、异常边界、降级策略
- **P2（一般）**：体验优化、排序逻辑、界面提示规范
